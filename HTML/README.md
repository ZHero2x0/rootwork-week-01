# Personal Dev Profile

I built a simple HTML developer profile website for ZHero.2x0 that introduces him, highlights his skills and projects, and includes a contact form.

## Main sections

- Header: name, title, and navigation links
- About section: short bio and profile image
- Skills section: core technologies and tools
- Projects section: featured work with links
- Contact section: message form and call to action
- Footer: branding and quick return link

## Semantic HTML choices

- header: for the top-of-page branding and navigation so the site starts with clear document structure.
- nav: for the menu links to make the page easier to navigate.
- main: to wrap the primary content and separate it from the header/footer.
- section: for the About, Skills, Projects, and Contact blocks to group related content.
- footer: for the copyright/branding area so the end of the page is clearly defined.

## Confusing & Interesting things?

I found nothing particularly confusing, but one interesting thing was that I spent way less time than I imagined on setting up the nav links and I did not have any issue with semantics.(Based on results from the html checker)
